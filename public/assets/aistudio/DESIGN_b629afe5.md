## Brand & Style

The design system embodies unapologetic turn-of-the-millennium glamor, blending aggressive Y2K cyber-futurism with high-fashion doll maximalism. Tailored for Gen Z digital natives, fashion-tech consumers, and nostalgia curators, the UI evokes vanity, fierce confidence, playful materialism, and high-octane club energy.

The aesthetic fuses tactile skeuomorphism, liquid chrome metallic finishes, and hyper-gloss glassmorphism over deep velvet obsidian depths. Visual signatures include high-gleam chrome bezels, liquid metal pill outlines, embossed sticker badges, sparkling 4-point starburst clusters, and animal-print textured overlays, paired with glossy neon highlights that simulate metallic reflections under flash photography.

## Colors

The palette is rooted in ultra-dark obsidian velvet backgrounds overlaid with hyper-saturated hot magenta, baby-pink metallics, and liquid chrome mirror highlights.

- **Primary (`#FF007F` / `#FF1493`):** High-voltage hot electric magenta. Used for primary interactive triggers, active tabs, glowing strokes, and emphasized display titles.
- **Secondary (`#FFB6C1` / `#FFC0CB`):** Soft gloss bubblegum baby pink. Acts as a balancing tone for secondary buttons, interactive fills, badge backdrops, and muted typographic accents.
- **Tertiary (`#E0E5EC` / `#C0C0C8`):** Mirror chrome and molten liquid silver. Applied to dynamic bevels, borders, starburst iconography, reflective highlights, and metallic trim.
- **Neutral Surface System (`#0E0712` base, `#18091E` elevated, `#260F30` high surface):** Deep obsidian noir with rich violet-wine undertones. Prevents the neon pinks from washing out and establishes an authentic midnight club VIP aesthetic.
- **Chrome Highlight (`#FFFFFF`):** Pure pinpoint specular reflection used on bevel ridges and sparkles.

## Typography

The typographic hierarchy bridges early 2000s cyber-experimental styling with strict UI legibility:

- **Headlines (`Syne`):** High personality, wide, sculpted display curves reminiscent of early-2000s glossy magazine covers and CD jewel cases. Headlines render in bold weights, often enhanced with metallic gradient fills (`linear-gradient(180deg, #FFFFFF 0%, #E0E5EC 40%, #FF007F 100%)`).
- **Body (`Plus Jakarta Sans`):** Balanced, modern geometric readability with soft, rounded terminals that maintain the playful aesthetic without sacrificing accessibility in multi-line paragraphs.
- **Labels & Microcopy (`Space Grotesk`):** Y2K cyber-deck technicality. All-caps treatments with expanded letter spacing mimic flip-phone UI headers, digital camcorder overlays, and metallic sticker tags.

## Layout & Spacing

The system runs on a 12-column fluid grid system across desktop views, collapsing to 6 columns on tablet (768px - 1024px) and 4 columns on mobile (<768px). 

Outer canvas boundaries leverage a generous margin to simulate framed digital portals or pocket-mirror viewfinders. Layout modules utilize an 8px base rhythm. Components rely on tight internal groupings coupled with dramatic structural section separations (`space-xl`), allowing high-contrast metallic cards to float distinctly over dark textured canvas backdrops.

## Elevation & Depth

Visual hierarchy does not use mundane drop shadows; it relies on multi-layer specular highlights, frosted jelly glass, and neon chrome luminescence:

- **Level 1 (Subtle Surfaces & Panels):** Obsidian tinted container (`rgba(24, 9, 30, 0.75)`) backed by a 16px blur filter, framed by a 1px metallic linear stroke (`rgba(224, 229, 236, 0.2)` transitioning to `rgba(255, 0, 127, 0.1)`).
- **Level 2 (Interactive Floating Cards):** Dual-layer outer glow consisting of a tight 0 2px 4px rgba(0, 0, 0, 0.8) base contact shadow and an ambient hot magenta halo (`0 0 20px rgba(255, 0, 127, 0.25)`). The top border features an inner specular bevel (`inset 0 1px 1px rgba(255, 255, 255, 0.6)`).
- **Level 3 (Modals, Overlays, Floating Badges):** Triple-layer glass depth: an aggressive inner bevel (`inset 0 2px 2px #FFFFFF`, `inset 0 -2px 4px rgba(255, 0, 127, 0.4)`), surrounded by high chrome borders and a wide atmospheric electric violet neon glow (`0 0 35px rgba(255, 20, 147, 0.45)`).
- **Texture Layering:** Translucent vector cheetah/leopard prints (rendered at 4%–8% opacity in soft magenta) applied exclusively as non-interactive pattern masks across Level 1 card backgrounds.

## Shapes

The shape system adopts a pill-shaped curvature (Level 3), invoking Y2K handheld beauty tech, lip-gloss compacts, and metallic capsule badges. 

Interactive items—such as buttons, chips, search bars, and tags—exhibit fully rounded capsule profiles (`rounded-full`). Container cards, modals, and preview tiles combine softened corners with sculpted bevel edges. Iconic 4-point starburst geometry is integrated as decorative cutouts, icon anchors, and structural badge terminals.

## Components

### Buttons
- **Primary Cyber-Gloss Button:** Fully rounded pill profile. Background is a vibrant vertical gradient (`linear-gradient(180deg, #FF3399 0%, #FF007F 60%, #D6006A 100%)`) with an inner top gloss highlight (`inset 0 1.5px 0.5px rgba(255, 255, 255, 0.75)`). Elevated by an outer magenta neon aura. Typography is set in `Space Grotesk` uppercase. On hover, triggers a liquid chrome sheen swipe animation.
- **Chrome Secondary Button:** Transparent dark glass core encased in a 2px liquid chrome gradient border (`#FFFFFF` to `#8A92A6`). Typography glows in `#FFB6C1`. On hover, fills with translucent molten silver (`rgba(224, 229, 236, 0.15)`) with an intensified silver rim.

### Chips & Badges
- Miniature sticker-style pills. Styled with an embossed metal effect: 1px silver border, high-contrast drop shadow, accompanied by a miniature 4-point chrome starburst icon prefix. Active chips illuminate in hot magenta; inactive chips rest in velvet purple noir.

### Cards
- Floating glassmorphism slabs over obsidian canvas. Cards feature 24px corner radii, a subtle semi-opaque leopard print watermark embedded in the base CSS layer, an inset specular border highlight simulating curved acrylic glass, and high-intensity hot pink glow effects when hovered.

### Input Fields
- Capsule-shaped input containers filled with `rgba(24, 9, 30, 0.85)`. Encased in a brushed aluminum hairline border (`#4A3B52`). Placeholder text uses baby pink at 50% opacity in `Space Grotesk`. On focus, the field activates with a 2px electric magenta ring and an outer neon bloom (`0 0 16px rgba(255, 0, 127, 0.4)`).

### Checkboxes & Radio Buttons
- Custom cyber-diamond and 4-point star shapes rather than standard circles and squares. Unchecked states show a brushed chrome outline with a dark obsidian center. Checked states fill with solid hot magenta and an embossed center silver star icon.

### Floating Floating Stickers & Accessories (Unique System Elements)
- **Glitter Badges:** Skewed, embossed metallic badges placed at 6-degree angles over imagery, simulating physical puffy metallic vinyl stickers.
- **Sparkle Starbursts:** Ambient micro-interactions rendering intermittent CSS twinkling animations on interactive element corners.
